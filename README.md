En este trabajo se desarrollo un Curriculum Vitae propio utilizando HTML5 y CSS. Para organizar la información utilicé etiquetas semánticas y diferentes CSS, incorporando Flexbox para trabajar la composición, distribución y relación entre los delementos de la página.

Componentes de la página - CV

Características de Head:
- Documento elaborado en idioma español.
- Vinculado a una hoja de estilos CSS externa.
- Incorporación de tipografía de Google Fonts.
- Incorporación de un favicon propio.

Elementos utilizados en la estructura Body:
- Header con navegación hacia las diferentes secciones del Curriculum Vitae.
- Presentación personal acompañada por una foto de perfil.
- Sección "Sobre mí" con una breve presentación personal.
- Sección "Experiencia" con información sobre trabajos, actividad freelance, emprendimiento y experiencia dentro de la UNLa.
- Sección "Formación" con información académica y formación complementaria.
- Sección "Trabajos realizados por mí" con una selección de proyectos de identidad visual, producción gráfica y estampado.
- Sección "Un poco más sobre mí" con información personal.
- Sección de perfiles y redes sociales.
- Footer con información e identidad de la Cátedra Wischñevsky.

Para la estructura utilicé etiquetas como header, nav, main, section, article, div, img y footer.

Información técnica
- Programa editor de código utilizado: Visual Studio Code.
- GitHub utilizado para alojar y compartir el proyecto.
- HTML5 para la estructura del contenido.
- CSS para la propuesta visual.
- Flexbox para organizar y distribuir diferentes elementos de la página.

Información sobre el diseño:
- La paleta cromática está compuesta principalmente por tonos beige y diferentes tonalidades de violeta.
- Se utilizó Roboto para textos y titulares.
- Se utilizó Lobster, disponible en Google Fonts, para destacar el nombre principal y algunos elementos del sitio.
- Se trabajaron diferentes jerarquías tipográficas para diferenciar títulos, subtítulos y textos.
- Se incorporó un favicon propio relacionado con la identidad visual del Curriculum Vitae.
- Las imágenes utilizadas corresponden a fotografías personales y trabajos realizados por mí.
